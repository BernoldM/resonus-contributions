# Resonus contribution previews

User-provided local app screenshots and silent recordings for the Resonus contributions. These previews have multiple local features enabled; they are not device verification of isolated upstream branches. Artist previews demonstrate the optional Apple artist source, not provider signatures. Android Auto shows appearance, not subscribed-view refresh behaviour.

This branch contains PR media only and is not part of the application changes. Video audio tracks were removed; video streams and original still images are unchanged. The media depicts third-party music artwork and app interfaces; no ownership of that artwork is asserted or additional license granted.
